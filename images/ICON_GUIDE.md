# 圖示說明

## 目前狀態
已建立一個臨時 SVG 圖示 (icon.svg),使用 🎯 emoji 作為圖標。

## 需要做的事
PWA 需要 PNG 格式的圖示:
- icon-192.png (192x192 像素)
- icon-512.png (512x512 像素)

## 方法 1: 使用線上工具轉換

### 步驟:
1. 打開 https://cloudconvert.com/svg-to-png
2. 上傳 icon.svg
3. 設定輸出尺寸為 512x512
4. 下載並重命名為 icon-512.png
5. 重複步驟,輸出 192x192,命名為 icon-192.png
6. 將兩個檔案放到 images/ 資料夾

## 方法 2: 使用 Favicon Generator

### 步驟:
1. 打開 https://realfavicongenerator.net/
2. 選擇一個圖片或使用文字
3. 產生後下載
4. 解壓縮後找到需要的尺寸
5. 重命名並放到 images/ 資料夾

## 方法 3: 自己設計

使用 Figma、Canva 或其他設計工具:
- 畫布尺寸: 512x512
- 背景色: #0f0f1e (暗色)
- 圖示: 簡單易辨識
- 圓角: 建議 80px
- 匯出為 PNG

## 臨時方案

如果暫時不想處理圖示,可以:
1. 繼續使用 SVG (某些瀏覽器支援)
2. 或註解掉 manifest.json 中的 icons 區塊
3. 之後再補上

## 範例設計概念

- 🎯 標靶 (目前使用)
- 👥 人群
- 💰 錢袋
- 🧧 紅包
- 📊 圖表
- 或使用你的 Logo

---

**重點: PWA 可以在沒有完美圖示的情況下運行,圖示只是為了更好的用戶體驗**
